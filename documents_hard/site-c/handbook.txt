LOCAL PRACTICE HANDBOOK — OBSERVATION PHASE
Eastfield Unit | Induction material | Not a protocol document

HOW TO USE THIS HANDBOOK
Written for staff joining the unit. It describes how the observation phase runs
here in practice. Where it appears to differ from the protocol, the protocol
is correct and the discrepancy should be raised with the site investigator.

1. THE OBSERVATION PHASE
This is local practice for the observation phase, written for induction. It does not replace the protocol and should not be read as doing so.

Observations are taken at a minimum interval of 240 minutes, which we believe is in line with the study protocol.

Concurrent anticoagulant therapy is permitted where a maintenance dose was established before enrolment.
STAFF SUPPORT
Questions about local practice go to the unit sister in the first instance.
Protocol questions go to the site investigator. Nothing in this handbook
overrides the protocol.
